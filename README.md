# Installation

1. Unzip this zipfile somewhere where the files will not be moved or deleted. (Not in your downloads folder)
2. To install the extension, go to chrome://extensions/, Or settings -> Manage Extensions
3. Enable the 'Developer Mode' toggle in the top right
4. Click 'Load Unpacked' and select this folder.

## Features
### Major Features
- Sort 'files' evidence alphabetically.  
- Backup 'free text' evidence locally.  
- Paste images from clipboard directly into 'free text' evidence.  
- Export your porfolio.  
### Minor Features
- Add Freetext shortcut.  
- Select all artifacts in snapshot.  
- Auto select name field on new artifact creation.  
- Remove popup notification for 'no saving' alert.  
- Remove banner and empty space on main page.
- Hide header
